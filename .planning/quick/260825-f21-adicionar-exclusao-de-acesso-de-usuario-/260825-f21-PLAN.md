<objective>
Adicionar a exclusão de acesso de usuário (hard delete de AuthUser) ao fluxo de
"alterar papel" da tela de gestão de usuários: botão "Excluir acesso" com
confirmação em duas etapas dentro do `change-role-modal.tsx`, endpoint
`DELETE /api/auth/users/{user_id}` restrito a admin e com bloqueio de
auto-exclusão, e uma migration que impede que a exclusão quebre o histórico de
solicitações de parâmetro já existente.

Purpose: hoje não existe caminho para revogar acesso de um usuário — só trocar
papel. Como `get_current_user` relê o usuário do banco a cada request (sem
blacklist de JWT), o hard delete já corta o acesso na próxima chamada
autenticada, sem trabalho extra de invalidação de sessão.

Output: endpoint de exclusão auditável e seguro no backend; UI de exclusão com
confirmação em duas etapas no frontend; histórico de parâmetros que sobrevive
à exclusão do usuário que solicitou/revisou uma mudança.
</objective>
