# Audit 2026-08-07 — automation OR Backend (brownfield)

**Repo:** `system-automation-backend`  
**Escopo:** Hardening de plataforma (CI, auth, deploy, Docker, contratos, obs)  
**Comparativo:** Collab API `collab-backend`  
**Estado do planejamento:** Milestone v1.2 (Phases 4–9) — **somente docs**; sem remediação executada neste commit de planning.

## Resumo executivo

O milestone Linx v1.1 (Phases 1–3) entregou schema/ingestão/escrita. Em paralelo, a plataforma operacional ainda permite **deploy sem testes**, **defaults de auth inseguros**, **OTP sem entrega em PROD**, **stack Celery/migrations fora do ECS**, **imagem Docker com deps de dev**, **docs/contratos dessincronizados** e **observabilidade incompleta**.
