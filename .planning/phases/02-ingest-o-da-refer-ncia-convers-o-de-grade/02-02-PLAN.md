    Implementar `def converter_grade_para_posicoes(grade: dict[str, int], referencia: dict[str, int], cd_prod_cor: str) -> tuple[dict[str, int], list[str]]`: inicializa `posicoes = {f"e{n}": 0 for n in range(1, 49)}`, `ignorados: list[str] = []`, `conflitos: list[str] = []`, `ocupante_da_posicao: dict[int, str] = {}`. Itera `grade.items()` (na ordem de inserção do dict, relevante para D-03): para cada `sg_tamanho, qtd`, busca `pos = referencia.get(sg_tamanho)`; se `pos is None`, adiciona `sg_tamanho` a `ignorados` e `continue` — NUNCA lançar exceção aqui (critério 5 do ROADMAP); se `pos` já está em `ocupante_da_posicao` com um `sg_tamanho` DIFERENTE do atual, registra em `conflitos` o aviso no formato EXATO `f"{tamanho_anterior}/{sg_tamanho}->pos{pos}"` (D-03); em seguida `ocupante_da_posicao[pos] = sg_tamanho` e `posicoes[f"e{pos}"] = qtd` (último processado vence). Ao final: se `ignorados` não vazio, `logger.warning("produto %s: tamanhos sem posição na referência: %s", cd_prod_cor, ignorados)` (D-04); se `conflitos` não vazio, `logger.warning("produto %s: conflito de posição na grade: %s", cd_prod_cor, conflitos)`. Retorna `(posicoes, ignorados)` — o 2º elemento existe para permitir asserts diretos no teste sem depender de `caplog` (nenhum teste do repositório usa esse padrão hoje).
